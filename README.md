# HR Analytics Dashboard Project

## Project Overview
This project focuses on analyzing HR data and transforming raw employee records into actionable business insights using Microsoft Excel.

The project involved:
- Cleaning and preparing HR datasets
- Performing HR data analysis
- Building 3 professional interactive dashboards
- Creating KPI cards and interactive charts
- Using slicers for dashboard interactivity
- Presenting business insights and recommendations

The dashboards help management monitor workforce demographics, employee performance, engagement, and HR investment effectiveness.

---

# Tools & Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Excel Formulas
- Interactive Dashboard Design

---

# Data Cleaning & Preparation

## Data Cleaning Tasks Performed

### 1. Remove Duplicates
- Checked duplicate records using Employee ID
- Removed duplicate rows

### 2. Change Date Format
Converted the following columns to Short Date Format:
- StartDate
- Training Date
- Survey Date
- DOB

### 3. Handle Missing Values
- Identified blank or missing values
- Filled and cleaned important missing records
